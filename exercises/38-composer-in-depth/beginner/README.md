# Exercise 38, beginner: a project's composer.json

`composer.json` in this folder belongs to a small project for a book club.
JSON has no comments, so the task is here. Add:

- the licence `MIT`;
- what it needs to run: PHP 8.5 or newer, and the mbstring extension (any version);
- an autoloader: classes in the namespace `BookClub\` are in the folder `src/`.

Then check your work: `composer exercise 38 beginner`
